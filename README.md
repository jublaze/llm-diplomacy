# Source-only publication candidate

This is a source snapshot of the Diplomacy experiment framework and its compatible report viewer. It excludes repository history, runtime memories, generated experiments, viewer report fixtures, dependencies, and build outputs. Read `framework/README.md` for the framework quickstart and `viewer/README.md` for viewer validation.

The offline DATC gate covers 172 entries: 155 match expectations, nine are declared project-policy divergences, one is an adapter limitation (ordinary 6.G.11 adjacent-convoy intent inference), and seven are historical alternatives. These results are not an unqualified standard-rules conformance claim; see `framework/docs/DATC_COVERAGE.md`. The standard map adaptation includes its own attribution and CC BY-SA 3.0 notice.

Full completed Luna results are packaged separately as a checksummed release asset, not included in this source history. See publication/README.md for the full-postgame policy, local verification and manual Pages deployment. No hosted release has occurred yet.
