# Legacy local public-release workflow

The older viewer-side projection workflow is retained only for historical
tests. Its CLI is disabled and it is not an approved deployment producer.

The current public packaging authority is a framework-produced Phase 5A
`postgame_public` projection. Follow `PUBLIC_BUILD_REHEARSAL.md`; do not use an
omniscient catalog, `public/reports`, or `dist` as public-build input.
